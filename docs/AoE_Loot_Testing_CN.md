# 范围自动拾取功能测试指南

## 概述

本文档提供范围自动拾取功能的全面测试场景和程序。它涵盖功能测试、配置验证、边缘情况和性能测试。

## 前提条件

测试前，请确保：
1. 服务器已使用 AoE 拾取更改编译
2. 配置文件已正确设置
3. 测试角色具有适当的权限和等级
4. 测试环境有多个生成的生物用于测试

## 配置测试

### 测试 1：功能启用/禁用

**目标**：验证主启用/禁用开关是否正常工作

**步骤**：
1. 在 mangosd.conf 中设置 `AoELoot.Enable = 0`
2. 重启服务器
3. 击杀多个附近的生物
4. 拾取一个生物
5. **预期**：仅显示所选生物的战利品
6. 在 mangosd.conf 中设置 `AoELoot.Enable = 1`
7. 重启服务器
8. 击杀多个附近的生物
9. 拾取一个生物
10. **预期**：合并多个尸体的战利品

**状态**：⬜ 通过 ⬜ 失败

---

### 测试 2：范围配置

**目标**：验证拾取范围设置是否按预期工作

**测试用例**：

#### 用例 A：默认范围（55 码）
```ini
AoELoot.Range = 55.0
```
- 在不同距离（40、50、60 码）击杀生物
- **预期**：55 码内的尸体被合并，超出的不合并

#### 用例 B：最小范围（5 码）
```ini
AoELoot.Range = 5.0
```
- 在 3、5 和 10 码处击杀生物
- **预期**：仅非常近的尸体被合并

#### 用例 C：最大范围（100 码）
```ini
AoELoot.Range = 100.0
```
- 在 90 码范围内击杀分散的生物
- **预期**：100 码内的所有尸体被合并

#### 用例 D：超出界限的值
```ini
AoELoot.Range = 2.0    # 低于最小值
AoELoot.Range = 150.0  # 超过最大值
```
- **预期**：值分别被限制为 5.0 和 100.0

**状态**：⬜ 通过 ⬜ 失败

### 测试 23：关闭未拾取窗口后可重新拾取

**目的**：验证打开 AoE 拾取窗口本身不会消耗源尸体的战利品。

**步骤**：

1. 击杀 3 个相距在 `AoELoot.Range` 内、各自拥有普通物品或金币的生物。
2. 打开尸体 A 的拾取窗口，确认窗口中出现来自尸体 B 和 C 的合并战利品。
3. 不拾取任何物品或金币，直接关闭拾取窗口。
4. 分别尝试再次打开尸体 A、B 和 C。

**预期**：三个尸体都仍可拾取；A、B 和 C 的战利品总量与步骤 1 一致，且没有重复或丢失。随后实际拾取 A 的合并窗口中的任一物品或金币后，已合并的源尸体才被标记为已拾取。

> **回归依据**：修复前，步骤 2 会立即清空 B/C 并移除它们的可拾取标志，因此步骤 4 失败。

> **状态**：⬜ 通过 ⬜ 失败
