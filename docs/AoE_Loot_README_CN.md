# 范围自动拾取功能 - 快速入门指南

## 什么是范围自动拾取？

范围自动拾取（AoE Loot）是一个生活质量功能，可以自动将附近多个尸体的战利品合并到单个拾取窗口中。当你拾取一个生物时，系统会搜索范围内的其他可拾取尸体，并将它们的物品和金币合并到主拾取窗口中。

## 快速开始

### 1. 安装

该功能已集成到代码库中。只需编译服务器：

```bash
mkdir build && cd build
cmake ..
make -j$(nproc)
```

### 2. 配置

编辑你的 `mangosd.conf` 文件并配置 AoE 拾取设置：

```ini
# 启用/禁用功能
AoELoot.Enable = 1

# 显示登录消息
AoELoot.Message = 1

# 搜索范围（码）(5.0 - 100.0)
AoELoot.Range = 55.0

# 在组队中启用
AoELoot.Group = 1

# 最大合并尸体数 (1 - 20)
AoELoot.MaxCorpses = 10
```

### 3. 启动服务器

正常启动服务器。该功能将立即生效。

## 如何使用

1. **击杀多个敌人**，使它们在近距离内（在配置的范围内）
2. **拾取一个尸体**，像平常一样
3. **自动接收**附近所有尸体的战利品在单个窗口中
4. **完成！** 无需逐个拾取每个尸体

## 故障排除

### 功能不工作？

1. 检查配置中 `AoELoot.Enable = 1`
2. 验证尸体在配置的范围内
3. 确保你对尸体有拾取权限
4. 检查 `AoELoot.Group` 是否正确设置

### 性能问题？

1. 将 `AoELoot.MaxCorpses` 降低到较小的值（例如 5）
2. 将 `AoELoot.Range` 降低到较小的半径（例如 30.0）

### 战利品缺失？

- 物品窗口有 16 个物品的限制。如果存在更多物品，一些将丢失
- 如果你有任务，任务物品应该始终出现
